# VideoGrab — دانلودر ویدیو + فایل منیجر (اندروید)

## ساخت و اجرا
1. پوشه VideoGrab را در Android Studio (Koala یا جدیدتر) باز کنید.
2. Gradle Sync ← Run روی گوشی (Android 10 / API 29 به بالا).
3. بار اول اجازه‌ی Notification و (برای حباب) «نمایش روی سایر اپ‌ها» را بدهید.

> کد کامپایل و روی دستگاه تست نشده؛ ممکن است در اولین Build به اصلاح کوچک نیاز باشد.

## روش‌های دانلود
- مرورگر داخلی: سایت را باز کنید، ویدیو را پخش کنید؛ دکمه‌ی دانلود لیست ویدیوها و کیفیت‌ها را نشان می‌دهد.
- اینستاگرام (Share): Share ← VideoGrab
- اینستاگرام (حباب): منو ⋮ ← «نمایش حباب شناور». در اینستاگرام Copy link ← لمس حباب.
- لینک مستقیم mp4 / m3u8 در نوار آدرس.

## امکانات
دانلود با ادامه (HTTP Range)، HLS با انتخاب کیفیت، ۳ دانلود هم‌زمان، اعلان پیشرفت،
فایل منیجر: جست‌وجو، فیلتر، مرتب‌سازی، انتخاب چندتایی، توقف/ادامه، تغییر نام، تامبنیل،
سرعت و ETA، حذف از لیست یا با فایل، ذخیره در گالری، اشتراک، پخش.

## محدودیت‌ها
- اندروید اجازه نمی‌دهد اپ دیگری ویدیوی داخل اپ اینستاگرام را بگیرد؛ پس Share / کپی لینک + مرورگر داخلی.
- اینستاگرام معمولاً نیاز به Login دارد و ساختار صفحه‌اش عوض می‌شود؛ استخراج گاهی کار نمی‌کند.
- DASH ممکن است تصویر و صدا جدا باشد. HLS رمزگذاری‌شده و DRM پشتیبانی نمی‌شود.
- خروجی HLS معمولاً .ts است.
- فقط محتوایی را دانلود کنید که حق دانلودش را دارید.
